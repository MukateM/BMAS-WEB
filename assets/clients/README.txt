Put client logo files in this folder.

Recommended formats:
- PNG or SVG
- Transparent background (preferred)

Recommended sizing:
- ~300px wide or larger (for crisp display)

Naming tips:
- use lowercase and hyphens, e.g. "acme-ltd.png"
- avoid spaces in filenames (best for website links)

After adding or renaming logos:
- update `clients.html` to include the new filenames and correct alt text
- optionally update the landing page logo preview in `index.html`
